# ECS Informatique

Site web réalisé pour **ECS Informatique**, avec pour objectif de présenter l'entreprise, ses services, ses offres et de permettre aux visiteurs de déposer une candidature.

🌐 **Live Demo:** https://ecs-informatique.vercel.app/

## 📋 Description

**ECS Informatique** est un projet de site web institutionnel développé puis adapté pour être déployé sur une plateforme moderne d'hébergement web.

Le projet a initialement été développé avec **ASP.NET MVC**, puis migré vers une version **statique** afin de simplifier le déploiement et permettre son hébergement sur **Vercel**.

Le site contient notamment :

* 🏠 Une page d'accueil
* 💼 Une page présentant les offres
* 📄 Une page de candidature
* 🔒 Une page de confidentialité
* 📱 Une interface adaptée aux différents écrans
* 🎨 Une interface web responsive
* ⚡ Un déploiement sur Vercel

## 🛠️ Technologies utilisées

* **HTML5**
* **CSS3**
* **JavaScript**
* **ASP.NET MVC** — version initiale du projet
* **Git / GitHub**
* **Vercel** — déploiement

## 🔄 Migration du projet

Le projet a connu une évolution en plusieurs étapes.

### 1. Version ASP.NET MVC

Le site a initialement été développé avec une architecture **ASP.NET MVC**, avec une séparation entre les vues et les ressources du site.

### 2. Migration vers une architecture statique

Afin de faciliter le déploiement sur des plateformes comme **Vercel** et **Netlify**, le projet a ensuite été adapté en site statique.

Les principales pages ont été converties en fichiers HTML autonomes tout en conservant les ressources front-end nécessaires.

### 3. Déploiement

La version statique actuelle est déployée sur **Vercel**.

🔗 **Site en ligne :** https://ecs-informatique.vercel.app/

## 🚀 Installation locale

Pour tester le projet localement, il suffit de cloner le repository :

```bash
git clone https://github.com/Joseph-Nostra/ECSInformatique-.git
```

Puis accéder au dossier :

```bash
cd ECSInformatique-
```

Comme il s'agit actuellement d'un site statique, il est possible d'ouvrir directement :

```text
index.html
```

Pour une meilleure expérience de développement, vous pouvez également utiliser **VS Code + Live Server**.
